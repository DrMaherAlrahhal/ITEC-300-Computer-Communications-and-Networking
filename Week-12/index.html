02 / The forwarding decision

Switched or routed backbone?

They connect networks, but their forwarding decisions are different. Select a model to see what it uses.

Switched backbone

Managed switches forward Ethernet frames using MAC addresses. VLANs help organize traffic. An oversized Layer 2 domain needs careful control of broadcasts and loops.

Example: A distribution switch forwards a frame toward the correct port within a VLAN.

Conceptual illustration; real networks may combine Layer 2 and Layer 3.

🔀 Layer 2

Forwards frames using MAC addresses. Useful in well-defined switching domains.

🧭 Layer 3

Forwards packets using IP networks and routing tables. Often easier to segment large campus networks.

🤝 Common design

Access switches connect users, while Layer 3 switches or routers connect VLANs, buildings and external networks.

✅ Five principles of a strong backbone

1. Capacity

Size uplinks for peak aggregate traffic, not one user.

2. Reliability

Avoid single points of failure with suitable alternate paths.

3. Segmentation

Use VLANs and IP subnets to separate network functions.

4. Security

Protect management access and apply appropriate policies.

5. Operations

Document, monitor, label, and test recovery procedures.
