How to read these waveforms

Unipolar NRZ: 1 = +V; 0 = 0V.

Polar NRZ-L: 1 = +V; 0 = −V.

AMI: 0 = 0V; each successive 1 alternates +V and −V (first mark +V).

Manchester: 0 = High→Low; 1 = Low→High, with a transition in the middle of every bit.
