Part A · CLO 3 · Prepare for Question 1

1. Networking Devices and Their Functions

Question 1 · 3 marks

Networks use different devices because each device has a particular job. When choosing a device, ask: What does it do? and Where would it be needed?

Switch

Connects wired devices in a local network. Uses MAC addresses to forward Ethernet frames toward the appropriate port.

Wireless Access Point (AP)

Allows Wi-Fi devices to join a network. Usually connects to a wired switch through Ethernet.

Router / Gateway

Connects different IP networks and forwards packets between them, such as a campus LAN and the Internet.

Server

Provides services or resources, such as shared files, a website, DHCP, or DNS.

Network Printer

Receives print jobs from authorized computers over the network.

Fiber-optic Link

Carries data as light over long distances; a strong option for linking buildings 500 m apart.

Ethernet Cabling

Uses copper conductors for wired connections. Typical twisted-pair Ethernet channel length is up to 100 m.

Firewall

Controls allowed and blocked network traffic according to security rules; may be built into a gateway.

Think of a university laboratory: Fixed desktop PCs need wired access, so a switch and Ethernet cabling are useful. For mobile laptops, an AP provides wireless access.
Practice before opening the assignment: Can you explain the difference between a switch and a router? Why would an AP be used in a classroom? Which component would help link buildings 500 m apart?

2. Network Services and Protocols

Question 2 · 4 marks

A protocol is a set of communication rules. A network service provides a useful function to devices or users. The assignment focuses on four important examples.

3. From Wi-Fi Connection to Website

Question 3 · 3 marks

When a student opens a university website, several devices and services work together. Understanding the sequence makes it easier to explain network communication.

  1. Join Wi-Fi: The laptop selects the university wireless network and connects through an access point. It may need to authenticate.
  2. Receive IP settings: A DHCP service typically assigns an IP address, gateway, and DNS server information.
  3. Look up the website: The laptop uses DNS to find the IP address of the university website.
  4. Send network traffic: IP packets travel through the network, potentially through a switch and router/gateway.
  5. Open the secure website: The browser establishes a secure HTTPS connection to the web server and requests the page.

Important distinction: The access point provides the wireless connection; DHCP provides IP configuration; DNS resolves names; HTTPS protects web communication. These are different jobs.

Part B · CLO 4 · Prepare for Question 5

5. Evaluate Reliability, Security, and Scalability

Question 5 · 2 marks
Reliability

How consistently the network stays available and communicates correctly. Think about quality cabling, reliable devices, maintenance, and avoiding single points of failure.

Security

How the network protects devices and information. Think about strong Wi-Fi authentication, access controls, firewalls, and keeping equipment updated.

Scalability

How easily the network can grow. Think about available switch ports, adding APs, planned IP address capacity, and expandable links.

How to write an evaluation

For each criterion, use the structure: design choice → why it helps → university example. Avoid simply writing “the network is secure” or “the network is reliable” without explaining how.

Practice example (not an assignment answer): A school adding another classroom may need extra switch ports and an additional access point. This is an example of planning for scalability.
Practice: Identify one possible network failure, two distinct security protections, and one realistic way the network could expand.

7. Individual Oral Discussion

Question 7 · 3 marks · Individual

Each student explains the group's network design in a short discussion with the instructor. You should understand the whole design, not only your assigned section.

1 mark · Technical understanding

Explain what the selected devices and protocols do.

1 mark · Design evaluation

Explain why the chosen network design is suitable for the university.

1 mark · Individual contribution

Describe your own responsibilities and what you completed.

Try these discussion questions

Why might a university need both switches and access points?

Think about the different roles of wired desktop computers and mobile Wi-Fi users. Explain the difference using your group's actual design.

Why does a device need DHCP and DNS?

Consider the difference between receiving network settings and finding the IP address of a website.

How would you explain your group's building-to-building connection?

Identify the chosen medium, its suitability for the distance, and how it connects to the rest of the design.

What would happen if the university added another classroom?

Explain whether your proposed network has enough capacity and what equipment might need to be added.

What exactly did you contribute to the assignment?

Be ready to identify the work you personally completed and explain how it helped the final design.

Before the discussion: Be ready to explain your diagram without reading from the report. Use clear technical reasons for each choice.
