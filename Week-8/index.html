Client

Device or app that asks for a service, such as a browser.

Server

Computer or virtual machine providing a service to clients.

Server software

Program that listens for requests and produces responses, such as a web server.

A server is not necessarily a special-looking machine: the word describes its role. One physical server may host several services or virtual machines.

03 · Server operating systems

What does an operating system do on a server?

The server operating system manages users, permissions, files, resources, networking, security, and background services. Server applications run on top of it.

👤 Accounts & permissions

Control which users can access folders or services.

⚙️ Services & processes

Start, stop, and manage web, file, or other server programs.

🛡️ Security & updates

Apply patches and configure protection.

💽 Storage & resources

Manage disks, memory, CPU time, and logs.

Choose a platform

Select either platform to explore typical use cases. Both can run important network services.
An operating system is not the same as the service: for example, a Linux server might run web server software, and a Windows Server system might run directory and file services.
