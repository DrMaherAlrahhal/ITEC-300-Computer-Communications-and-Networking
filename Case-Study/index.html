2 · Quick networking concepts

Switch

Connects devices in a local network and forwards Ethernet frames using MAC addresses.

Router / gateway

Connects different IP networks and forwards packets toward their destination.

Wireless access point

Connects wireless clients to the local network using Wi-Fi.

DHCP

Automatically provides client IP configuration, such as IP address, gateway and DNS server.

DNS

Translates domain names into IP addresses for clients.

HTTPS

Protects web communication using TLS encryption.

Bandwidth vs. throughput

Bandwidth is a link capacity measure; throughput is the actual data transfer achieved.

Firewall

Applies rules to permit or block network traffic.

LAN vs. WAN

LAN covers a local area; WAN connects networks across larger distances.

Mini practice: A laptop joins Wi-Fi but cannot open a website. What should you check?

Check Wi-Fi association, the client IP configuration (DHCP), gateway reachability, DNS name resolution and the website connection. These are different possible failure points; a Wi-Fi connection does not guarantee Internet access.

Mini practice: What is a simple network demand calculation?

Estimated total demand = number of active users × estimated Mbps per user. Example: 30 × 2 Mbps = 60 Mbps. This is a planning estimate, not a measured throughput guarantee.

4 · Build your project step by step

Choose the problem

Write one sentence describing the problem, its users, and what your app will do. Keep only one main networking function.

Open VS Code and create a folder

For a simple interactive website, use index.html, style.css and script.js. A Python/Streamlit app is also acceptable, but requires Python to run.

Write a precise AI prompt

Include the scenario, user inputs, expected outputs, networking rules, preferred technology, and at least two tests. Ask the assistant to explain the generated code.

Run and inspect the application

For a static site, open index.html in a browser. For Streamlit, install its dependencies and run the app using the command below.

python -m pip install streamlit
python -m streamlit run app.py

Fix errors and improve

Copy the exact error to your coding assistant, request a focused fix, and test again. Record a few actual prompts for your report.

Publish to GitHub

Create a repository, upload the code, and add a README.md describing what the app does, how to run it, and the test scenarios. GitHub Pages can host static HTML/CSS/JS, but does not run a Streamlit backend.

Example README.md outline
# Project Title

## Networking problem
What problem does this app address?

## Main feature
What inputs and outputs does it have?

## How to run
Steps and any dependencies

## Testing
Test inputs and expected results

## Team contributions
What did each member do?
How to make a good AI prompt

Weak: “Make a networking website.”

Better: “Build a simple HTML/CSS/JS Wi-Fi capacity estimator for students. Inputs: users and assumed users per access point. Output: estimated access point count rounded up. Explain assumptions, validate zero/negative inputs, include two tests, and explain the code.”

5 · Test and evaluate your work

A project is not complete because it looks attractive. It must give meaningful, correct networking results.

TestWhat to record
Normal inputInput, expected output, actual output, pass/fail
Boundary or unusual inputZero users, unavailable route, failed server, or another relevant case
Networking correctnessWhy the displayed result follows the networking concept

Evaluation: Describe one strength, one limitation, and one realistic improvement. If your app simulates data, label it as simulated and do not claim it measures a live network.
