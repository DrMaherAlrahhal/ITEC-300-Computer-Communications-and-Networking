Step 1 · Data and signals

What is a signal, exactly?

Data is the information we want to communicate, such as the word HELLO. Computers represent that information as bits (0s and 1s). To send those bits, network hardware produces a physical signal: changing electrical voltage in copper, light in fiber, or radio waves in wireless communication.

Signals have measurable properties. Amplitude describes their strength, frequency counts cycles per second, and period is the time for one cycle (period = 1 ÷ frequency). Now change the controls to see these ideas.

Step 2 · ASCII and number systems

How do computers represent English letters?

ASCII assigns a number to each English letter, digit, and basic symbol. For example, the capital letter A has ASCII decimal code 65. Computers store that code as bits. We can write the same number in decimal (65), 8-bit binary (01000001), or hexadecimal (41). These are three representations of the same ASCII value.

Binary uses 0 and 1; an 8-bit number has place values 128, 64, 32, 16, 8, 4, 2, 1. Hexadecimal uses digits 0–9 and letters A–F (10–15). Two hexadecimal digits can represent one byte. Try typing HELLO or DATA in the lab and compare all three forms.

Step 3 · Line coding

Turn bits into a visible signal

After a message becomes bits, the sender must represent each 0 and 1 as a physical signal. This is called line coding. Different coding rules create different signal patterns for the same bits.

Unipolar NRZ uses +V for 1 and 0 V for 0. Polar NRZ-L uses +V for 1 and −V for 0. Bipolar AMI uses 0 V for 0 and alternates +V and −V for successive 1s. Manchester makes a transition halfway through every bit (here, 1 = low → high and 0 = high → low). That midpoint change helps the receiver stay synchronized. Compare the same bits below.
