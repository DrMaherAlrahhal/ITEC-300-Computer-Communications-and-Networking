What is a signal, exactly?

Data is the information we want to send. A signal is a physical change that represents that data. The same bits may be carried by changing voltage, light, or radio waves.

Signal explorer

Discover three useful terms

Amplitude

How strong or tall the signal is. Increase the amplitude slider and watch the wave grow.

Frequency

How many complete cycles occur each second. Increase frequency and watch more cycles appear.

Period

The time for one complete cycle. Higher frequency means a shorter period: Period = 1 ÷ Frequency.

The sliders show a conceptual visualization, not the exact waveform used by Wi-Fi or Ethernet. The digital example changes between two discrete levels.

How does a computer understand letters?

Computers store text using character codes. A character such as A has a numeric code. An encoding such as UTF-8 converts characters into bytes, which we can display as binary.

Character-by-character explanation

CharacterUnicode code pointUTF-8 byte(s)
Example: the capital letter A has ASCII value 65, which is 01000001 in 8-bit binary. ASCII letters have the same byte values in UTF-8.
A character and a byte are not always the same thing. Some Unicode characters need multiple UTF-8 bytes.

ASCII vs Unicode vs UTF-8 — three different ideas

ASCII

An older code with values 0–127, covering English letters, digits, and basic symbols.

Unicode

A standard that assigns code points to characters from many languages and symbol sets.

UTF-8

A widely used way to encode Unicode characters into one or more bytes.

Turn bits into a visible signal

Character encoding answers “Which bits represent this text?” Line coding answers “How can those bits be represented by changes in a physical signal?”

Build your own bit pattern

What is different?

NRZ-L (simplified convention)

Each bit occupies one time interval. In this demo: 1 = high voltage and 0 = low voltage.

Manchester (one convention)

Every bit has a transition in the middle. In this demo: 1 = low → high; 0 = high → low.

These are teaching conventions. Real technologies define exact signal levels, polarity, timing, and other rules. A bit pattern alone does not specify a physical voltage or radio waveform.
The receiver must know the same coding rule to interpret the received signal correctly.

One complete idea

A student types HI → the application uses character encoding → the computer obtains 01001000 01001001 → the network equipment sends physical signals → the receiver recovers the bits and decodes them as HI.

This is the key connection between data, codes, and signals.
