Part 1 · Concept

1. What is a MAC address?

MAC means Media Access Control. A MAC address identifies a network interface, such as a computer’s Ethernet or Wi-Fi interface.

When a computer sends an Ethernet frame, the frame includes a source MAC address (sender) and a destination MAC address (intended receiver).

Example: Three computers are connected to a network switch.
ComputerMAC addressSwitch port
PC AAA:AAPort 1
PC BBB:BBPort 2
PC CCC:CCPort 3
AA:AA, BB:BB, and CC:CC are shortened teaching examples. A real Ethernet MAC address is normally 48 bits, for example 00:1A:2B:3C:4D:5E.

What is a switch?

A network switch connects wired devices inside a LAN. It receives Ethernet frames and decides which port to use to send them.

PC A → Ethernet cable → Switch → Ethernet cable → PC B

What is a MAC address table?

A switch keeps a table of MAC addresses it has learned and the ports where those addresses can be reached.

Learned MAC addressPort
AA:AAPort 1
BB:BBPort 2

This means the switch can reach PC A through Port 1 and PC B through Port 2. But the switch does not know this automatically. It learns from frames that arrive.

Part 1 · Practical question

2. How does a switch learn MAC addresses?

Question: PC A, PC B, and PC C are connected to a switch on Ports 1, 2, and 3. Their MAC addresses are AA:AA, BB:BB, and CC:CC. Initially, the MAC address table is empty. PC A sends a frame to PC B, and PC B replies. What happens at each step?

Step 1 — The MAC table is empty

The switch has not received any frames. It does not yet know which MAC address is reachable through which port.

MAC address table now:

MAC addressPort
——

Step 2 — PC A sends a frame to PC B

The frame arrives on Port 1. Source MAC = AA:AA. Destination MAC = BB:BB. The switch reads the SOURCE address and learns AA:AA → Port 1. It does not learn BB:BB just because BB:BB is the destination.

MAC address table now:

MAC addressPort
AA:AAPort 1

Step 3 — The switch looks for BB:BB

The switch searches its table for destination BB:BB. It cannot find it. The switch FLOODS the frame out the other ports: Port 2 and Port 3. PC B accepts the frame because BB:BB matches its MAC address. PC C ignores it. The table still contains only AA:AA → Port 1.

MAC address table now:

MAC addressPort
AA:AAPort 1

Step 4 — PC B replies to PC A

The reply arrives on Port 2. Source MAC = BB:BB. Destination MAC = AA:AA. The switch learns BB:BB → Port 2 because BB:BB is now the SOURCE of an incoming frame.

MAC address table now:

MAC addressPort
AA:AAPort 1
BB:BBPort 2

Step 5 — The switch forwards the reply

The switch searches for destination AA:AA and finds it on Port 1. It sends the reply only through Port 1, not Port 3. This is known unicast forwarding.

MAC address table now:

MAC addressPort
AA:AAPort 1
BB:BBPort 2

Part 2 · Concepts

3. What are wired and wireless LANs?

Wired Ethernet LAN

Devices connect using physical Ethernet cables, usually through a switch.

Example: Fixed desktop PCs in a computer laboratory.

Why? Stable connection, suitable for devices that do not move.

Wireless Wi-Fi LAN

Devices connect using radio signals through a wireless access point (AP).

Example: Laptops and tablets in a university library.

Why? Students can move around within Wi-Fi coverage.

Switch, access point, and router: what is the difference?

DeviceWhat it doesExample
SwitchConnects wired devices using EthernetSix desktop PCs
Access pointProvides Wi-Fi connections to wireless devicesSix laptops
RouterConnects different networksUniversity LAN to Internet
Can wired and wireless devices communicate?
Yes, when they are part of the same LAN and network settings permit it. The access point connects the Wi-Fi side to the wired LAN.
Part 2 · Practical question

4. Design a wired + wireless LAN

Question: A university lab has 6 fixed desktop PCs and 6 laptops used by students who move around. How should we connect all 12 devices to one LAN?

Step 1 — Connect the desktop PCs

Choose wired Ethernet. The PCs stay in one place, so connect each PC to a switch with its own Ethernet cable.

PC 1 → Port 1, PC 2 → Port 2, ... PC 6 → Port 6.

Step 2 — Connect the laptops

Choose Wi-Fi. All six laptops connect wirelessly to an access point. The access point connects to the switch using one Ethernet cable.

Step 3 — Count the equipment

EquipmentNumberWhy
Desktop PCs6Wired devices
Laptops6Wi-Fi devices
Switch1Connects the wired LAN
Access point1Connects the Wi-Fi laptops
Ethernet cables7Six PCs + one access point
Switch ports used7Six PCs + one access point
RouterOptionalNeeded to reach other networks
Important: Six Wi-Fi laptops do not need six separate switch ports. They connect through the same access point. An 8-port switch is enough for this simple design if no additional wired connections are needed.

Step 4 — Follow a message

Wired PC → Ethernet cable → Switch → Ethernet cable → Access point → Wi-Fi → Laptop

When a wired PC sends data to a Wi-Fi laptop, the switch delivers the traffic toward the access point, and the access point sends it over Wi-Fi to the laptop.
