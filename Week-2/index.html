05 · Fiber and performance

Why send data using light?

Fiber carries light, supports high bandwidth and long-distance links, and resists electromagnetic interference.

Bandwidth = capacity of the road. Data rate = traffic actually using the road. This is a simplified teaching analogy.

Which is better: copper or fiber?

🔌 Copper (twisted pair)

Usually lower cost and easier to install for short LAN connections. Uses electrical signals and can be affected by EMI.

✨ Fiber-optic

Supports longer distances and higher bandwidth; uses light and strongly resists EMI. Often costs more and needs careful installation.

Neither is always better. The correct choice depends on the network requirement.
