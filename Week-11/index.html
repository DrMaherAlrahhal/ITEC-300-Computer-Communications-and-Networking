01 · Routing · Try it

How does a router choose the next hop?

When a packet must reach another network, a router reads the destination IP address and uses a routing table to choose where to send it next. A route metric can help choose between available routes.

Routing vs switching

Switch: mainly forwards Ethernet frames within a LAN using MAC addresses.

Router: forwards packets between IP networks using destination IP addresses.

What is a routing table?

A list of destination networks and corresponding next hops/interfaces. A default route provides a fallback when no more specific route matches.

02 · Multiplexing · Animated simulator

One link, many users. How?

Multiplexing combines multiple communication streams over a shared link. At the other end, demultiplexing separates them. Compare three ways to share capacity.

Pick a technique to see how three users share one link.
The shared link has limited capacity; a multiplexing method organizes access to it.
TDM

Separate streams by time slots. Each user transmits in a different turn.

FDM

Separate streams by frequency bands. Different signals can be sent at the same time.

Statistical multiplexing

Share link capacity dynamically when users have packets to send; common in packet networks.

03 · Compression · Live text laboratory

Can we send the same message using fewer symbols?

Lossless compression preserves every bit of the original data. Try a simple learning example: Run-Length Encoding (RLE) replaces repeated characters with counts.

Original
AAAAABBBBCCCCCC

RLE result

Important: This demonstration counts characters, not compressed file bytes. Real formats use additional coding and headers; RLE can even expand data with few repeated characters.

🔐 Lossless

Exact recovery: source code, spreadsheets, database backups, ZIP or PNG-style use cases.

🎥 Lossy

Smaller audio, images, or video by discarding some information; quality may change.

Choose a use case to understand the trade-off.
